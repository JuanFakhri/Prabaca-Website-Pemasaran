## About Prabaca

Most HR systems only **record the past** — attendance, payroll, and leave are neatly stored, but it is still up to you to interpret them. Prabaca adds a layer that others don't have: **intelligence that reads the future**. It learns the patterns in your team's data, predicts risk, and recommends what to do next.

This repository hosts the product's marketing landing page.

## Highlighted features

Three AI capabilities that set Prabaca apart:

- **Resignation Radar** — a 90-day resignation-risk score for each employee, with transparent reasons and an AI-generated retention plan.
- **Anonymous Pulse** — honest employee feedback without fear; AI anonymizes identities and clusters everything into themes, not names.
- **HR Copilot** — an assistant you can ask in plain language that drafts HR documents instantly.

Plus a complete HRIS: real-time attendance, leave management with schedule-conflict detection, payroll with Indonesian BPJS & PPh 21 components, recruitment, performance, and an employee directory.

## Page highlights

## Run locally

Just open `index.html` in a browser — no installation required.

## Deploy to GitHub Pages

1. Upload `index.html` (and `prabaca-banner.png`) to this repo's `main` branch.
2. Open **Settings → Pages**.
3. Under *Source*, choose **Deploy from a branch** → branch `main` → folder `/ (root)` → **Save**.
4. Wait ~1 minute; the site goes live at `https://<username>.github.io/<repo-name>/`.
